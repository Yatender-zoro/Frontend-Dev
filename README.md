# Frontend-Dev

✅ Skills I Practiced

HTML – structure, semantic elements, block vs inline
Built multiple small pages using headings, tables, images, and forms. Got comfortable setting up page structure and embedding external stuff using iframes (like YouTube videos and maps).

CSS – selectors, box model, flexbox, grid, animations
Styled layouts from scratch: spacing, borders, gradients, hover effects, and smooth transitions. Learned how Flexbox and Grid handle alignment and page structure without chaos-level CSS.

Bootstrap – components + responsive design
Used Bootstrap's grid system, cards, buttons, navbars, and utilities to build layouts faster without writing everything from scratch. Also used predefined breakpoints for responsiveness.

Media Queries – making layouts adjust to screen size
Made pages mobile-friendly. Tweaked layouts and font sizing so the design doesn’t explode on smaller devices.
